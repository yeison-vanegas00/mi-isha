# 💜 Perdóname, mi amor

Página 100% estática (HTML + CSS + JavaScript). Sin backend.

## Desplegar en GitHub Pages

```bash
git init
git add .
git commit -m "Para ti 💜"
git branch -M main
git remote add origin https://github.com/TU_USUARIO/TU_REPO.git
git push -u origin main
```

Luego en GitHub: **Settings → Pages → Source: Deploy from a branch → `main` / `(root)` → Save**.

En 1–2 minutos estará en `https://TU_USUARIO.github.io/TU_REPO/`.

## Personalizar

Edita al inicio de `script.js`: `NOMBRE`, `FOTOS`, `RAZONES` y `FRASES`.
La carta está en `index.html` (sección `#carta`).
